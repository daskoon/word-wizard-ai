# vision01 - Implement Auto-Vision Implementation Plan

## Overview
Rebuild the Vision Digitization pipeline to support full Facebook Messenger screenshots with zero user cropping. 

## Current State Analysis
- `App.tsx`: Sends raw base64. Latency is high for large images.
- `geminiService.ts`: Uses `gemini-1.5-flash` with a minimal prompt. It often misses the grid or misinterprets UI as tiles.

## Implementation Approach
1. Add a `processImageForAI` utility in `App.tsx` to downscale and grayscale the image before sending.
2. Upgrade the prompt in `geminiService.ts` to use "Visual Anchors" (e.g., the Green TL corner squares) to define the 11x11 coordinate system.
3. Move to `gemini-2.0-flash-001` for superior multimodal grounding.

## Phase 1: Client-Side Preprocessing
### Overview
Reduce payload size and enhance contrast to help the AI "see".
### Changes Required:
#### 1. word-wizard-ai/src/App.tsx
**Changes**: Implement image resizing.
```typescript
const processImageForAI = (base64Str: string): Promise<string> => {
  return new Promise((resolve) => {
    const img = new Image();
    img.src = base64Str;
    img.onload = () => {
      const MAX_WIDTH = 1024;
      const scale = Math.min(1, MAX_WIDTH / img.width);
      const canvas = document.createElement('canvas');
      canvas.width = img.width * scale;
      canvas.height = img.height * scale;
      const ctx = canvas.getContext('2d');
      if (ctx) {
        ctx.filter = 'contrast(1.2) brightness(1.1)'; // Boost legibility
        ctx.drawImage(img, 0, 0, canvas.width, canvas.height);
        resolve(canvas.toDataURL('image/jpeg', 0.7)); 
      } else { resolve(base64Str); }
    };
  });
};
```
