# ui01 - Implement Cyberpunk UI Implementation Plan

## Overview
Transform the UI into a high-performance "Cyberpunk" interface with deep dark mode, neon accents, and real-time terminal feedback.

## Current State Analysis
- Components are inconsistent (mixed dark/light mode).
- Feedback is minimal (spinners only).
- Visuals are "basic af".

## Implementation Approach
1. Create a `NeuralLog` component to display streaming status updates.
2. Update all components (`MoveResult`, `RackInput`, `StrategyCard`, `Tile`) to use a unified dark/neon theme.
3. Inject a `TerminalOverlay` with scanline effects.
4. Use `framer-motion` for complex layout transitions.
